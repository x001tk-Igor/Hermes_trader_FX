# Hermes FX — MQL5-советник

Один инструмент на график. Двенадцать тактик внутри, у каждой свой magic.

## Слои и почему граница между ними жёсткая

| Слой | Файл | Знает | НЕ знает |
|---|---|---|---|
| Сигнальный | `Modules/Tactics.mqh` | бары, индикаторы | позиции, лоты, риск, разрешения |
| Бюджет риска | `Modules/RiskBudget.mqh` | открытый риск, equity | какая тактика просит |
| Движок корзины | `Modules/Basket.mqh` | позиции, средневзвешенную | откуда взялся сигнал |
| Мост | `Modules/Bridge.mqh` | файлы управляющего | торговую логику |

Граница нужна **ради измеримости**: тактику можно прогнать в изоляции только
если она не знает о позициях и лотах. Изоляция — единственный способ узнать,
есть ли у тактики собственный эдж, а это главный вопрос проекта.

## Два инварианта, которые нельзя нарушать

**1. Советник работает без управляющего.** В тестере стратегий моста нет.
Разрешения только СУЖАЮТ то, что советник и так готов сделать, и никогда не
расширяют. Нет файла — нечего сужать. Запрет по умолчанию означал бы, что
проверить советник можно только на живом счёте.

**2. Связывающий лимит — деньги, а не счётчик позиций.** Полный выбой одной
корзины стоит ~1.25% депозита. Двенадцать тактик со своими корзинами на одном
символе дают 15%, на трёх — 45% при заявленной максимальной просадке 5%.
Счётчик позиций такого не ловит, бюджет ловит по построению.

## Состояние по фазам

- **Ф0 ✅** каркас, слои, реестр тактик, компиляция 0/0
- **Ф1** исполнение: открытие корзины, доливка, перенос стопов
- **Ф1.5 ✅** бюджет риска (`RiskBudget.mqh`)
- **Ф2** логика 4 тактик: C1, C2, S6, S7
- **Ф3** арбитраж + одиночные прогоны каждой тактики
- **Ф4** мост: чтение разрешений, журнал, пульс (каркас готов)
- **Ф5** ВОРОТА: A/B усреднения + есть ли у тактик эдж в одиночку
- **Ф6** ИИ-управляющий
- **Ф7** форвард на демо
